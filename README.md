# Investor Readiness in the AI Era — Event Flyer

Live animated flyer for the Founders Hub session with Rho × Zendesk × LvlUp Ventures.

- **`index.html`** — fully self-contained (no build step, no dependencies):
  Bayer-dithered risograph design, four-speaker panel, animated WebGL
  grain-gradient band, and a "Save Your Seat" button wired to the RSVP form
  (https://tally.so/r/Y5XY1v). Mobile-responsive; respects reduced-motion.

## Deploy on Vercel

Import this repo → Framework preset: **Other** → no build command,
output directory: root. That's it — it's a single static file.
